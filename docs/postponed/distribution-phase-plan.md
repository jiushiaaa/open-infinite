# 后置发行路径计划

> 用途：记录发行、安装包和在线体验的后置路线。当前主线仍是世界沙盘体验深化；发行路径只有在本地产品体验稳定且用户明确要求时才进入。

## 1. 后置原因

当前用户价值还在世界运行、角色自主、主观记忆、干预后果、世界代偿、长正文和作者采纳质量上。发行、部署和商业化会扩大维护面，但不会自动改善小说世界体验。

## 2. 触发条件

进入本文计划前，至少满足：

1. 本地世界沙盘主链可被普通用户稳定跑通。
2. 长正文、卷宗阅读和作者采纳的主要读感问题已有一轮真实样本验收。
3. 用户明确要求安装包、云端体验或商业化。
4. 已确认 API key、日志、对象存储、认证和计费边界不会泄漏或误耗费。

## 3. 路线

| 路径 | 目标 | 状态 |
| --- | --- | --- |
| 本地 clone | 保留开发者和高级用户一键启动路径 | 已有 start-local 脚本，继续维护 |
| GitHub Release 安装包 | 降低非开发者启动成本 | 后置 |
| 服务器在线体验 | 提供免安装试用 | 后置 |
| 商业化加固 | 多租户、认证、对象存储、计费、限额 | 后置 |

## 4. 当前不做

- 不为发行提前重构产品主线。
- 不把对象存储、认证、计费塞进默认本地开发路径。
- 不在默认测试里加入真实外网或真实付费调用。
- 不把发行计划写回根目录当当前下一刀。

当前下一步仍应从 `../unfinale-current-optimization-backlog.md` 中选择。
