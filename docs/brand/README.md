# 未终章品牌资产

> 品牌名：未终章  
> 英文名：Unfinale  
> 技术底座：LNE / `living_novel_engine` 仍作为代码包、CLI 与环境变量前缀沿用。

## 文件

| 文件 | 用途 |
| --- | --- |
| `unfinale-logo.svg` | 横向产品标识：图标 + 中文名 + 英文名，适合 README、文档页和后续前端顶栏。 |
| `unfinale-icon.svg` | 仅图标版本，适合 favicon、应用图标和紧凑导航。 |
| `unfinale-logo-concept-light.png` | Imagegen 生成的轻量概念稿，用作视觉参考，不作为最终可编辑源文件。 |

## 设计语义

- 书页：小说与章节。
- 分叉线：世界线、读者干预与平行结局。
- 朱砂终点：被重新点亮的可能结局。
- 留白与浅纸色：避免“活体”一词带来的生物实验感，转向更温暖的创作工具气质。

后续接入前端时，优先使用 SVG 源文件；PNG 概念稿只用于视觉对照。
