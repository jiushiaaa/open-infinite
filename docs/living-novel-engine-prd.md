# 未终章产品 PRD

> 用途：记录未终章的产品定位、用户价值、主体验和验收口径。当前实现事实以 `../memory.md` 为准；文档分层以 `index.md` 为准；世界沙盘执行路线以 `unfinale-world-sandbox-remodel-prd.md` 为准；真实未完成优化集中在 `unfinale-current-optimization-backlog.md`。

## 1. 产品定位

未终章不是“下一段文本生成器”，而是一个会继续运行的小说世界：

```text
故事世界 / 天命书 / 角色主观记忆
  -> 多 Agent 沙盘轮次
  -> 读者干预与世界代偿
  -> 检查点与世界线演化
  -> 多视角正文
  -> 作者采纳或继续推演
```

用户进入的是同一个世界里的不同场景能力：天命书、世界沙盘、世界正史卷、主锚点卷、角色个人卷、势力卷、事件多视角、世界线、检查点和作者采纳台。

## 2. 目标用户与场景

| 用户 | 场景 | 产品应满足 |
| --- | --- | --- |
| 读者 | 续写断更小说、拯救意难平、观察平行世界线 | 干预被世界吸收或抵抗，后果进入状态和后续章节 |
| 作者 | 大纲压力测试、角色自主推演、采纳涌现剧情 | 沙盘结果可读、可编辑、可定稿、可进入下一章 |
| 设定爱好者 | 创世、构建角色关系和势力冲突 | 世界规则、天命书、角色记忆和卷宗能持续沉淀 |

## 4. 当前真实缺口

当前缺口不是“没有页面 / 没有 API”，而是第一版体验还需要更像一部活着的小说。具体后续优化以 `unfinale-current-optimization-backlog.md` 为准，核心方向包括：

- 真实 LLM 多 Agent 多轮策略博弈、长期关系、势力资源和跨轮结算。
- 长正文读感、视角稳定、真实文风一致性和连续阅读节奏。
- 跨章节误会、伏笔、证据锚点和长线卷的持续回收。
- Reviewer 从局部重写走向整章风格润色、可回滚对照和真实模型编辑器。
- 世界状态、因果债、代偿和角色主观记忆被下一轮真实决策消费。

## 5. 非目标

以下方向不作为当前默认产品路线：

- GraphRAG / Zep / Temporal Memory 重型 provider 试验。
- 默认 hybrid vector 替换 BM25。
- 发行安装包、服务器在线体验、多租户、认证、对象存储、计费。
- OpenAPI / typed client 面板深化。
- 纯工程健康报告，但没有新的小说世界体验。

## 6. 验收口径

一项产品切片只有在用户能感到以下至少一项增强时，才算主线有效：

- 世界会运行。
- 角色会自主。
- 角色会记得。
- 干预有后果。
- 角色可能反抗。
- 世界会代偿。
- 章节来自世界演化。

技术上还必须满足：Web UI 可见、API/artifact additive、失败有空态或明确错误、默认测试隔离外网、文档同步到当前事实和历史日志。
