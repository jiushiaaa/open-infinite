```text
导入 / 创世

  -> 多 Agent 世界沙盘轮次

  -> 干预投放与世界线代偿
  -> 世界自演检查点
  -> 多视角活体小说 / 连续阅读
```

- 世界会运行。

- 角色会记得。
- 干预有后果。
- 角色可能反抗。
- 世界会代偿。
- 章节来自世界演化。
