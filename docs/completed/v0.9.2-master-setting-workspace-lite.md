# v0.9.2 MasterSetting Workspace Lite 收口说明

> 收口日期：2026-06-01

## 目标

v0.9.2 的目标是在长篇共创闭环之后，把项目级设定资产从“导入后落盘的文件”变成作者/编辑可核对、可轻量修正的工作台：

```text
项目工作台 -> 设定资产聚合 -> 前端设定面板 -> 白名单轻编辑 -> 备份与保存报告
```

该版本是 Lite 收口，不做完整作者工作台，也不把人物、时间线、伏笔、章节摘要做成多表编辑系统。

## 已完成范围

- `GET /api/stories/<slug>/project-workspace` additive 返回 `master_setting_workspace`：
  - 数据源为 `memory/master_setting.yaml`、`memory/character_states/`、`memory/timeline.yaml`、`memory/plot_threads.yaml` 与 `memory/chapters/`。
  - 返回 `summary`、`sections`、`world`、`characters`、`timeline`、`plot_threads`、`chapter_briefs`、`capabilities`、`next_steps` 与 `warnings`。
  - `master_setting.yaml` 缺失或损坏时降级为 `missing` / `damaged`，工作台不白屏、不 500。
- 长篇项目工作台新增「设定工作台」面板：
  - 展示世界规则、力量限制、地点、势力、人物状态、时间线、伏笔线和章节摘要。
  - 右侧项目资产面板显示「设定状态」。
  - 对对象/数组型设定条目做安全格式化，避免 `[object Object]` 或英文占位。
- `POST /api/stories/<slug>/master-setting` 支持白名单轻编辑：
  - 允许字段：`display_name`、`genre`、`world_rules`、`power_system_limits`、`forbidden_additions`。
  - 保存前备份 `backups/<timestamp>/memory/master_setting.yaml`。
  - 保存后写 `memory/master_setting_update_report.json`。
  - 坏 slug 返回 400，缺故事返回 404，损坏或缺失 MasterSetting 返回 409，非白名单 payload 返回 400。
- 前端「设定工作台」新增最小写控件：
  - 支持编辑作品名、题材、世界规则、力量限制、禁用设定。
  - 保存后先本地更新面板并显示成功提示，再刷新项目工作台。

## 收口证明

本版本由四个小刀组成：

- MasterSetting Workspace Summary-A
- MasterSetting Workspace Panel-B
- MasterSetting Workspace Edit-C
- MasterSetting Workspace Frontend-D

Frontend-D 的本地渲染冒烟使用临时项目目录，不修改仓库样例数据：

```powershell
cd D:\AI\open-infinite\engine
$env:LLM_API_KEY=''
$env:SEEDREAM_API_KEY=''
$env:LNE_MOCK='1'
$env:LNE_PROJECTS_DIR='<temp-projects-dir>'
$env:LNE_OUTPUTS_DIR='<temp-projects-dir>\_outputs'
python -m living_novel_engine.cli browse --host 127.0.0.1 --port 8766 --no-open

cd D:\AI\open-infinite\engine\ui
$env:LNE_API_TARGET='http://127.0.0.1:8766'
pnpm run dev -- --host 127.0.0.1 --port 5174
```

冒烟结果：

- 「设定工作台」显示为已就绪、可编辑。
- 点击「编辑设定」后可编辑作品名、题材、世界规则、力量限制和禁用设定。
- 点击「保存设定」后出现「设定已保存」提示，新作品名和规则内容同屏可见。
- 浏览器控制台无 error / warn。

## 边界

- 不改 `run_scene` 默认行为。
- 不修改 run artifact 契约：`chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json`。
- 不编辑人物状态、时间线、伏笔、章节摘要。
- 不同步 `world.yaml`，避免把轻编辑误当成完整导入重写。
- 不引入完整作者工作台、多人协作、字段级权限或富文本编辑。
- 不引入 Zep、图数据库、OASIS、CAMEL 或 LangGraph。
- 不做云端队列、对象存储、多租户项目空间或商业级审计。
