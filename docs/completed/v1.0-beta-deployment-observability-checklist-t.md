# v1.0-beta Deployment Observability Checklist-T 收口说明

## 1. 范围

本刀把本地部署后的关键观测信号聚合成只读清单，放进设置抽屉，方便在不接云端监控的前提下核对“本地服务跑起来后该看哪里”。

## 2. 已完成

- 新增 `get_deployment_observability_checklist()`。
- 新增 `GET /api/settings/deployment-observability`。
- 清单聚合本地部署就绪、本地冒烟、配额用量、内存 job、项目审计时间线、版权审批检查和发布前检查。
- 设置抽屉新增「部署观测清单」只读区，展示已具备/需留意数量、云端观测状态、前 6 条信号和中文下一步。
- 可选 `story_slug` 仍走安全校验；非法参数返回 400，缺项目返回 404。

## 3. 边界

- 只读聚合本地观测证据，不 tail 日志、不写 artifact、不打外网。
- 不读取或展示明文密钥，不返回 `LLM_API_KEY` / `SEEDREAM_API_KEY` 等环境变量名。
- 不接云端观测、对象存储、持久队列、真实认证或计费系统。
- 不改变 `run_scene`，不影响 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
