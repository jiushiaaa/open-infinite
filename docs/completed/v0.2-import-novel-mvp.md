# v0.2 Import Novel — 最小闭环设计

> 版本：2026-05-28（v0.2 完整版收口）  
> 状态：**已交付**（PR-A + PR-B + PR-C）  
> 前置：v0.1.3 已收口（`intervene` → `resume continue` → `resume intervene`）

## 1. 目标

让用户上传 **3–10 章** 自己的 `txt` / `md`，经 LLM 抽取世界锚定文件，人工微调后，**最终**复用 `lne intervene` / `resume` 链路——不再依赖内置《天荒城残夜》。

**v0.2 全阶段不做**：网页抓取、卷级管理 UI、facts.jsonl 全量检索、MiroFish 接入、世界线 Web 浏览器。

### 1.1 分 PR 交付（重要）

| PR | 范围 | 验收 |
| --- | --- | --- |
| **PR-A** | 导入、写 `projects/`、`validate-project` | **不要求** `intervene` |
| **PR-B** | `load_story`、imported `intervene`、样例规则通用化或隔离 | mock 下 imported 项目能三分叉 |
| **PR-C** | 真实 LLM 双 pass 抽取（`llm_extractor.py`） | 已收口 |
| **v0.2.1** | `resume` 支持 imported project | 已收口 |

**测试基线**：`pytest -q` → **90 passed**。

## 3. 命令面

### 3.1 导入命令（推荐先用内置 fixture）

```bash

# 自建目录（须先创建 chapters/*.md）

```

### 3.2 PR-B 起才启用

```bash

```

### 3.3 v0.2.1

```bash
lne resume continue <run_id> --branch branch_a   # run 须带 story_slug=imported project

```

### 3.4 `import-novel` 参数（建议）

| 参数 | 说明 |
| --- | --- |
| `path` | 章节目录或合并文本文件 |
| `--name` / `-n` | 项目 slug（`[a-z0-9-]+`） |
| `--anchor` | 干预锚定章：默认最后一章；可 `last` / `3` / `chapter_003` |
| `--genre` | 题材提示（默认 `xianxia`，写入 style 草案） |
| `--mock` | 使用固定抽取模板，不调 LLM |
| `--max-chapters` | 上限 10，默认 10 |

## 4. 目录结构

**原则**：`projects/<slug>/` 与 `samples/<slug>/` **文件同构**，便于 PR-B 复用 loader；PR-A 只保证能写入且 `validate-project` 通过。

```text
engine/
├── samples/                    # 内置样例（不变）
│   └── tianhuang-night/
└── projects/                   # 用户导入（已 gitignore）
    └── my-story/
        ├── source/
        ├── world.yaml
        ├── characters.yaml
        ├── open_threads.yaml   # 可选
        ├── canon_chapter.md
        ├── prologue.md           # 可选
        ├── canon_opening.md      # 可选
        ├── anchor_proposal.yaml  # 人工对照，不参与运行时
        ├── import_meta.json
        └── style_hint.md         # 可选
```

### 4.1 与内置样例字段对齐

`world.yaml` → `StoryWorld`：`id`, `title`, `display_name`, `canonical_place_name`, `source_type: imported`, `rules[]`, `locations[]`, …

`characters.yaml` → `CharacterAgent`：至少 1 个 `present_in_scene: true`，`id` 为英文 snake_case。

`canon_chapter.md` = 干预锚定章 **原文**。

## 6. 代码改动与已知技术债

### 6.1 PR-A 改动范围

| 模块 | 改动 |
| --- | --- |
| `import/`（新包） | `splitter`, `mock_extractor`, `writer`, `validator` |
| `cli.py` | `import-novel`, `list-projects`, `show-project`, `validate-project` |
| `tests/` | `test_import_mock.py`, `test_validate_project.py`（**无** `test_intervene_imported`） |

**PR-A 不碰**：`orchestrator/`、`resume/`、`samples/loader.py` 的运行时路径。

### 6.2 PR-B 必须处理：天荒城硬编码

当前引擎在 **builtin 样例** 上打磨了大量专属逻辑；imported 项目若直接 `intervene`，会被这些规则污染或误触发。

| 位置 | 问题 |
| --- | --- |
| `orchestrator/scene_runner.py` | 场景推进绑定样例角色/地点 |
| `orchestrator/scene_rules.py` | 听雨轩、竹林、传讯玉简、墨青烟等事件规则 |
| `agents/character_agent.py` | `lin_fan` / `lin_wan_zhou` 等分支反应 |
| `orchestrator/narrative_constraints.py` / `canon_guard.py` | 天荒城称谓、正史、资源锁 |
| `output/writer.py:51` | 无 `sample_slug` 时写死 `tianhuang-night` |
| `resume/loader.py` | `DEFAULT_SAMPLE_SLUG`；`project_characters_from_parent` 仍 `load_sample(parent.sample_slug)` |

**PR-B 策略（二选一或组合）**：

1. **隔离**：`source_kind == "imported"` 时跳过天荒城 `scene_rules` 子集，仅保留通用合约（OOC、未声明设定、基础三分支主题）。
2. **通用化**：把地点/资源/角色 ID 从规则中抽成 `world.yaml` / `characters.yaml` 驱动（工作量大，可分期）。

无论哪种，PR-B 须同步：

- `intervention.json` / `meta.json`：`story_slug`, `source_kind`（勿再默认天荒城）
- `load_story(slug)` 替代 scattered `load_sample`
- `resume` 读 `story_slug`（完整 resume 可仍放 v0.2.1）

### 6.3 PR-B：Loader 统一接口
