# v0.9.0-alpha Long Novel Creation Loop 收口说明

> 收口日期：2026-06-01

## 目标

v0.9.0-alpha 的目标是把长篇上传、项目资产、分支运行、审计、选择世界线和章节导出串成第一条可验证的长篇共创闭环：

```text
上传/导入 -> 记忆与导入检查 -> 分支运行 -> 评审与审计 -> 选择世界线 -> 导出章节 -> 写入收口记录
```

## 已完成范围

- 章节导出与父链合集导出，导出内容带来源说明、AI 生成说明、评审摘要和版权边界。
- `creation_loop` 项目工作台清单、完成度、阻塞动作、判定依据和 alpha closeout 报告。
- `GET /api/stories/<slug>/creation-loop-closeout` HTTP 验收入口。
- `lne creation-loop-closeout <slug>` CLI 验收入口，支持 `--json`、`--require-ready`、`--write-report`。
- 推荐世界线评审、设为起点、选择后审计、范围回放快捷动作和审计前置 requirements。
- `selected_worldline.json` 起点持久化、`POST /api/jobs/resume-continue` 显式续写 job。
- 低风险静态审计提示不再阻断 alpha closeout；中高风险、缺失实体、缺评审、缺选择或缺导出仍会阻断。
