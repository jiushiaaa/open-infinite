# v1.0-beta Auth Boundary Checklist-U 收口说明

## 1. 范围

本刀把认证接入前的边界整理成设置页只读清单，明确当前仍是本地单人操作模式，不伪装成已经具备真实登录、团队空间或请求级 ACL。

## 2. 已完成

- 新增 `get_auth_boundary_checklist()`。
- 新增 `GET /api/settings/auth-boundary`。
- 清单聚合账号/项目空间边界、权限矩阵草案、请求级 ACL 缺口、项目空间映射和部署观测边界。
- 设置抽屉新增「认证边界清单」只读区，展示已具备/需留意数量、认证执行状态、检查项和中文下一步。
- 输出明确 `auth_enforced=false` 与 `external_services_required=false`。

## 3. 边界

- 只读定义认证接入边界，不创建用户、不接登录 provider、不执行 ACL、不写 artifact。
- 不读取或展示明文密钥，不返回 `LLM_API_KEY` / `SEEDREAM_API_KEY` 等环境变量名。
- 不接真实认证、团队空间、云端多租户、对象存储或计费系统。
- 不改变 `run_scene`，不影响 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
