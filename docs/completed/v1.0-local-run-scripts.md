# v1.0-local Local Run Scripts 收口说明

## 范围

本刀为本地 clone 用户新增一键运行脚本底座：

- Windows：`scripts/start-local.ps1`
- macOS / Linux：`scripts/start-local.sh`

脚本目标是让用户在已经 clone 仓库后，用一个命令完成依赖检查、依赖安装、后端启动、前端启动和本地入口打开。

## 使用方式

Windows：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start-local.ps1
```

macOS / Linux：

```bash
bash scripts/start-local.sh
```

轻量自检：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start-local.ps1 -CheckOnly -NoBrowser
```

```bash
bash scripts/start-local.sh --check-only --no-browser
```

## 行为

- 检查 Python、Node.js 与 pnpm；缺 pnpm 时优先尝试 `corepack enable`。
- 创建 `engine/.venv`。
- 安装后端依赖：`python -m pip install -e engine`。
- 安装前端依赖：`pnpm install`。
- 启动后端：`python -m living_novel_engine.cli browse --host 127.0.0.1 --port 8765 --no-open`。
- 启动前端：`pnpm run dev -- --host 127.0.0.1 --port 5173`。
- 等待后端模型配置 API 与 Vite 首页可访问。
- 打开 `http://127.0.0.1:5173/`。
- 日志写入 `.local-run/`。

## 边界

- 这不是安装包，不内置 Python、Node 或 pnpm runtime。
- 不读取、写入或打印用户模型密钥。
- 不设置真实 provider key，不打外网测试模型连接。
- 不接云端部署、认证、对象存储或计费系统。
- 不改变 `run_scene` 默认行为和既有 artifact 契约。

## 验证

- 新增 `tests/test_local_run_scripts.py` 静态验收脚本内容和密钥边界。
- Windows `.ps1` 保持 ASCII，避免 Windows PowerShell 5.1 解析 UTF-8 无 BOM 中文字符串失败。
- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start-local.ps1 -CheckOnly -NoBrowser` 通过。
- 完整后端回归 `713 passed`。
- 前端 `pnpm run build` 通过。
- 本地 HTTP smoke 通过：Vite 首页 200，模型配置 API 返回 5 个文本模板、2 个视觉模板，且 `plaintext_key_returned=false`。
