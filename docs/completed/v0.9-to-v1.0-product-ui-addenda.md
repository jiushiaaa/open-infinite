# v0.9-v1.0 Product UI Addenda

> 来源：从 `v0.7-product-web-app-ui-spec.md` 拆出。该文件只记录 v0.9.0-alpha 之后在产品前端上的增量 UI：长篇创作闭环、Provider/Cost、MasterSetting、商业化边界、本地模型配置等。v0.7 主规格仍见 `v0.7-product-web-app-ui-spec.md`。
> 当前状态：以下增量均已收口；真实云端多租户、对象存储、认证、计费、安装包与服务器部署仍不在本文范围。
## 0.0 v1.0-local Model Configuration UX 增量（已收口）

设置抽屉新增本地模型配置状态，优先服务用户自己配置文本模型/视觉模型的本地体验。

- 新增 API（additive）：
  - `GET /api/settings/model-configuration`
  - 返回 `summary`、`sections`、`warnings`、`next_steps`。
- UI 露出：
  - 设置抽屉新增「常用接口模板」，可自动填入 OpenAI 兼容、DeepSeek、通义千问、火山方舟等接口地址和模型名。
  - 设置抽屉新增「使用真实文本模型生成」开关，直接控制默认是否继续走本地模拟。
  - 设置抽屉新增「视觉模型模板」和视觉密钥单独清除按钮。
  - 设置抽屉新增「模型配置状态」区。
  - 展示已就绪数量、当前模式、文本模型、连接测试、默认推演、视觉模型、密钥边界和中文下一步。
  - 保存设置、清除文本模型密钥或清除视觉模型密钥后刷新模型配置状态。
- 当前隐藏：
  - 设置抽屉不再展示「成本估算」输入。
  - 设置抽屉不再展示「计费边界」可见区；底层只读 API 保留。
- 边界：
  - 不打网络、不落盘、不返回明文 Key 或环境变量名。
  - 不接真实计费、支付、余额、webhook、GitHub Release 安装包或服务器部署；本地一键启动脚本已另见 `completed/v1.0-local-run-scripts.md`。

## 0.0 v0.9.1 Provider Gateway Summary-A 增量（已收口）

运行设置层新增 provider/cost 摘要，为后续设置页可视化和成本聚合提供只读数据源。

- 新增 API（additive）：
  - `GET /api/settings/providers`：返回 `version`、`routing`、`providers`、`cost_policy` 和 `warnings`。
  - `GET /api/settings/provider-usage`：返回 `version`、`story_slug`、`run_count`、`record_count`、`missing_usage_record_count`、`totals`、`by_provider`、`records` 与 `cost_estimate`；可选 `story_slug` 过滤，非法值 400。
- 数据边界：
  - `providers` 当前包含主文本模型与 Seedream 视觉模型，只返回脱敏尾号、base_url、model、active/configured、fallback 与 usage 来源。
  - `routes` 只读列出读者干预生成、主题创世、导入抽取、视觉资产生成四个入口当前对应的 provider、mode、runner 和 fallback。
  - `routing.mode=single_provider`；未配置文本密钥或默认 mock 时走 mock，视觉模型未配置/关闭时走占位图。
  - `cost_policy` / `cost_estimate` 仍只读保留在 API；当前 UI 暂不展示价格估算。
- UI 边界：
  - 设置抽屉新增「模型与用量状态」只读区，展示 provider 状态、模型名、累计用量、输入/输出用量、缺失 usage 记录提示和 warning。
  - 「模型与用量状态」同步展示入口路由矩阵，明确各生成入口当前走主文本模型、本地模拟、Seedream 或占位图。
  - 当前设置抽屉已撤下「成本估算」输入区，用量状态只展示 token 统计。
  - 保存设置或清除文本模型密钥后刷新 provider 状态。
  - 不打网络、不落盘、不返回明文 Key 或环境变量名。

## 0.0 v0.9.0-alpha Chapter Export 增量（已收口）

在阅读工作台上新增一个轻量闭环动作：用户选中世界线后，可直接导出当前章节 Markdown。

- 新增 API（additive）：
  - `GET /api/runs/<run_id>/branches/<branch_id>/chapter-export`：返回 `filename`、`content_type`、`content_md` 与 `metadata`；坏 id 400，缺章节 404。
- UI 露出：
  - `ChapterReader` 顶部新增「导出章节」按钮。
  - 导出成功/失败均在阅读区局部显示中文状态，不影响章节阅读或右侧机制档案。
- 边界：
  - 导出内容包含来源说明、AI 生成说明、世界线评审摘要和当前章节正文。
  - 不写回 `chapter.md`，不改 `run_scene` 默认行为，不导出上传原作全文或 holdout 私有正文。

## 0.0.0.7 v0.9.0-alpha Creation Loop Alpha Closeout Report 增量（已收口）

- API 行为：
