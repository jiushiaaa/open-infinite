# v1.0-beta Worldline Selection Audit Hook-M 收口说明

> 日期：2026-06-01
> 范围：世界线选择写操作接入本地审计日志
> 代码入口：`select_worldline()`、`memory/project_audit_log.jsonl`

## 1. 收口目标

本刀延续关键写操作审计接入，把长篇创作闭环中的“设为下一章起点”纳入本地审计日志。用户选择世界线后，除了既有 `selected_worldline.json` 合成审计项，还会追加真实 JSONL 事件，便于后续按项目追踪关键决策。

## 2. 已完成

- `select_worldline()` 成功写入 `selected_worldline.json` 后，会追加 `worldline_selected` 审计事件。
- 审计事件写入导入项目的 `memory/project_audit_log.jsonl`，并带上 `artifact_path=selected_worldline.json`、`run_id`、`branch_id` 与 `branch_label`。
- `GET /api/stories/<slug>/audit-log` 会继续聚合该事件。
- 审计追加白名单新增 `worldline_selected`，用于真实世界线选择事件。
- 内置样例仍保持既有行为：选择记录写入 `outputs/story_selections/`，审计日志追加冲突会降级跳过，不把 builtin 选择变成 409。

## 3. 未做

- 不接真实账号、团队空间、认证 provider 或请求级 ACL。
- 不接云端不可篡改审计存储、对象存储、数据库或队列。
- 不把所有写操作一次性接入审计；本刀只覆盖世界线选择。
- 不改变推荐世界线排序，不驱动 runner，不自动写正史账本。
- 不改 `run_scene` 默认行为，不改变既有 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
