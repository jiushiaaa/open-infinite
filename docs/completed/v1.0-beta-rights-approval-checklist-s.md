# v1.0-beta Rights Approval Checklist-S 收口说明

## 1. 范围

本刀把项目级版权/来源声明、授权确认和审计记录聚合成只读版权审批准备度清单，放在长篇项目工作台中，方便在导出或未来公开分享前先看清本地证据缺口。

## 2. 已完成

- 新增 `get_rights_approval_checklist()`。
- 新增 `GET /api/stories/<slug>/rights-approval-checklist`。
- 检查清单聚合项目版权/来源声明、授权确认、local export 许可、`rights_reviewed` 审计事件和公开发布保护项。
- 长篇项目工作台「项目审计日志」区新增「版权审批检查」只读面板，展示已具备/需留意数量、前 4 条检查项和中文下一步。
- `story_slug` 仍走安全校验；非法 slug 返回 400，缺项目返回 404。

## 3. 边界

- 只读检查版权审批准备度，不执行真实审批、不开放公开发布、不写 artifact。
- 不读取或展示明文密钥，不返回 `LLM_API_KEY` / `SEEDREAM_API_KEY` 等环境变量名。
- 不接真实认证、对象存储、云端不可篡改审计、云端观测或计费系统。
- 不改变 `run_scene`，不影响 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
