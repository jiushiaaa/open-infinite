# v1.0-beta MasterSetting Audit Hook-L 收口说明

> 日期：2026-06-01
> 范围：设定轻编辑写操作接入本地审计日志
> 代码入口：`update_master_setting()`、`memory/project_audit_log.jsonl`

## 1. 收口目标

本刀延续 Copyright Audit Hook-K，把第二个关键产品写操作接入本地审计日志：用户保存 `memory/master_setting.yaml` 白名单字段后，除了既有 `master_setting_update_report.json` 合成审计项，还会追加真实 JSONL 事件，验证关键写操作逐步落入同一审计账本。

## 2. 已完成

- `update_master_setting()` 成功写入 `memory/master_setting.yaml` 与 `memory/master_setting_update_report.json` 后，会追加 `master_setting_updated` 审计事件。
- 审计事件写入 `memory/project_audit_log.jsonl`，并带上 `artifact_path=memory/master_setting.yaml`、`report_path` 与 `changed` 字段。
- `GET /api/stories/<slug>/audit-log` 会继续聚合该事件。
- 审计追加白名单新增 `master_setting_updated`，用于真实设定保存事件。
- 现有 `POST /api/stories/<slug>/master-setting` 错误语义保持不变：坏 slug 400，缺项目 404，损坏设定 409。
