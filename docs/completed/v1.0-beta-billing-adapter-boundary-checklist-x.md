# v1.0-beta Billing Adapter Boundary Checklist-X 收口说明

## 1. 范围

本刀把计费从“可估算成本”和“配额执行边界”推进到“计费 adapter 前置边界清单”：明确真实计费前需要稳定 usage、单价估算、计费身份、硬配额语义、支付 provider adapter、发票退款轨迹和审计事件。

## 2. 已完成

- 新增 `get_billing_adapter_boundary_checklist()`。
- 新增 `GET /api/settings/billing-adapter-boundary`。
- 清单聚合 Provider Usage、Quota Enforcement Boundary、Auth Boundary 与未来计费 adapter 项。
- 设置抽屉新增「计费边界」只读区，展示已具备/需留意数量、计费写入状态、检查项和中文下一步。
- 输出明确 `adapter_implemented=false`、`billing_writes_enabled=false` 与 `external_billing_required=false`。

## 3. 边界

- 只读定义计费 adapter 前置边界，不创建 customer、subscription、checkout、webhook、invoice 或 refund。
- 不写余额、账单、套餐、欠费或支付状态，不读取或展示明文密钥，不返回 `LLM_API_KEY` / `SEEDREAM_API_KEY` 等环境变量名。
- 不接真实支付 provider、webhook 签名、对账系统、发票系统、云端监控、日志平台或告警系统。
- 不改变 `run_scene`，不影响 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
