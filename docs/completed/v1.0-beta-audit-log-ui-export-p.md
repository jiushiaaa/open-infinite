# v1.0-beta Audit Log UI & Export-P 收口说明

## 1. 范围

本刀把 v1.0-beta 已建立的本地项目审计日志从 API/schema 推到项目工作台可见，并提供本地 Markdown 导出，方便用户复盘关键操作链。

## 2. 已完成

- 新增 `export_project_audit_log()`。
- 新增 `GET /api/stories/<slug>/audit-log/export`。
- 导出内容包含项目摘要、事件时间线、来源产物数、warning 与中文分享边界提示。
- 项目工作台新增「项目审计日志」只读区，展示事件数、来源产物、最近事件、warning 和下一步。
- 项目工作台提供「导出 Markdown」按钮，下载前用中文确认审计日志分享边界。

## 3. 边界

- 不写新的项目 artifact，不覆盖 `memory/project_audit_log.jsonl`。
- 导出不包含事件 `metadata`，避免手工 JSONL 中残留的敏感字段进入 Markdown。
- 不提供公开分享发布、版权审批、真实账号、请求级 ACL、云端不可篡改审计存储、对象存储、数据库或计费系统。
- 不改变 `run_scene`，不影响 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
