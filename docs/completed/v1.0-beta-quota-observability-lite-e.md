# v1.0-beta Quota & Observability Lite-E

> 收口日期：2026-06-01
> 性质：本地配额与观测口径，只读报告，不执行硬配额、不接真实计费或云端监控。

## 目标

在 provider/cost、审计日志、权限矩阵和版权声明之后，把当前本地运行过程里已经可观测的数据收束为一份商业化前的配额/观测口径：token usage、内存 job 状态、软配额提示和后续监控缺口。

## 已完成

- 新增 `service.quota_observability.get_quota_observability_lite()`。
- 新增只读 API：`GET /api/settings/quota-observability`。
- 支持可选 `story_slug` 过滤，非法 `story_slug` 返回 400。
- 复用既有 `get_provider_usage_summary()`，读取 `generation_meta.usage` 的 run 数、record 数、token totals、缺失 usage 计数、provider 汇总和手动成本估算。
- `JobStore` 新增 additive `snapshot()` 与 `max_jobs`，用于只读汇总当前进程内 job 状态。
- 报告返回：
  - `quota_policy.mode=not_enforced`
  - `usage`
  - `jobs.status_counts`
  - `jobs.kind_counts`
  - `jobs.retention`
  - `observability.external_monitoring=not_configured`
  - `warnings`
  - 中文 `next_steps`

## 边界

- 不执行硬配额，不阻断生成请求。
- 不接真实计费、余额、账单或支付系统。
- 不接云端监控、日志平台、告警系统或多租户账号。
- 不读取、不回显、不记录任何 API Key。
- 不写 artifact，不改变任何 run/project 产物。
- 不改变 `run_scene` 默认行为。
- 不改变 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
