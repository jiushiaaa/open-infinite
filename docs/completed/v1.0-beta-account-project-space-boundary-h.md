# v1.0-beta Account Project Space Boundary-H 收口说明

> 日期：2026-06-01
> 范围：本地账号语义、项目空间清单和未来团队归属迁移边界
> 代码入口：`get_account_project_space_boundary()`、`GET /api/settings/account-project-space-boundary`

## 1. 收口目标

本刀承接 Commercial Hardening Scope-A 中 `account_project_space.local_first_next`：先定义项目空间清单和迁移边界，保持本地 artifact 可被后续平台层托管，同时避免直接接认证、团队空间或 ACL 拦截。

## 2. 已完成

- 新增 `living_novel_engine.service.account_project_space.get_account_project_space_boundary()`。
- 新增 `GET /api/settings/account-project-space-boundary`。
- 报告返回 `account_model.mode=local_single_operator`、`source_of_truth=local_file_artifacts`、`auth_provider=not_configured`、`team_space=not_configured`。
- `local_inventory` 只读统计本地导入项目、内置样例、run 产物和世界线选择记录，不暴露绝对路径或密钥。
- `project_spaces` 明确 `projects/`、`samples/`、`outputs/run_*/` 与 `outputs/story_selections/` 的当前归属、未来空间、默认可见性和迁移规则。
- `future_metadata_fields` 预留 `owner_account_id`、`team_id`、`visibility`、`created_by`，但当前不写入任何 artifact。
- `migration_boundaries` 明确 slug 不是身份、samples 只读、run 继承项目空间，以及当前不承诺跨设备同步。

## 3. 未做

- 不接真实账号、团队空间、认证 provider、成员邀请、跨设备同步或请求级 ACL。
- 不新增权限拦截，不改变现有 API 行为。
- 不写 artifact、不迁移项目、不上传文件。
- 不改 `run_scene` 默认行为，不改变既有 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
