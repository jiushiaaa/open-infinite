# v1.0-local Model Configuration UX 收口说明

## 范围

本刀把设置页从“商业化/计费检查继续前推”临时切回本地用户最需要的模型配置体验：

- 新增 `get_model_configuration_summary()`。
- 新增 `GET /api/settings/model-configuration`。
- 设置抽屉新增「模型配置状态」只读区。
- 设置抽屉新增文本模型常用接口模板和视觉模型模板，帮助真实用户填写自己的 provider。
- 设置抽屉把“使用真实文本模型生成”放到模型连接区，减少用户在默认参数区找开关的成本。
- 设置抽屉隐藏当前不需要的「计费边界」区和成本估算输入，保留底层只读 API 以兼容既有文档和测试。

## API 契约

`GET /api/settings/model-configuration` 返回：

- `version=v1.0-local-model-configuration-ux`
- `mode=read_only_model_configuration_summary`
- `summary`：文本模型是否配置、是否 mock、视觉模型是否配置、是否启用视觉、连接测试是否可用、是否返回明文 key、ready/attention 数量。
- `sections`：文本模型、连接测试、默认推演、视觉模型、密钥边界。
- `text_model_presets`：OpenAI 兼容、DeepSeek、通义千问、火山方舟和自定义接口模板。
- `visual_model_presets`：Seedream 5.0 Lite 和关闭视觉资产模板。
- `form_guidance`：保存范围、明文密钥边界和连接测试说明。
- `warnings` 与 `next_steps`：中文提示。

该接口只读、不联网、不落盘、不创建模型客户端、不返回明文密钥或环境变量名。

## UI 行为

- 设置抽屉在「模型连接」之后展示「模型配置状态」。
- 「常用接口模板」只自动填写接口地址和模型名，不填写密钥。
- 「使用真实文本模型生成」勾选后会把默认 mock 关闭；未勾选时继续本地模拟。
- 「视觉模型模板」可一键切换 Seedream 或关闭视觉资产；视觉密钥支持单独清除。
- 用户可以直接看到当前是“本地模拟”还是“真实模型”，文本模型、视觉模型和密钥边界是否就绪。
- 保存设置、清除文本模型密钥或清除视觉模型密钥后刷新模型配置状态和 provider 状态。
- 用量区保留 token 统计，但不再展示计费或价格估算。

## 边界

- 不改 `run_scene` 默认行为。
- 不新增真实认证、真实计费、真实配额拦截或线上多用户能力。
- 不移除已经存在的计费边界 API，只是从当前设置页主体验里撤下可见计费区。
- 不在前端存储或回显 API Key 明文。
