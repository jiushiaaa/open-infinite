# v1.0-beta Commercial Audit Log Schema-B

> 收口日期：2026-06-01
> 性质：本地项目审计日志 schema 与只读聚合，不写日志、不接云端不可篡改存储。

## 目标

在 Commercial Hardening Scope-A 明确审计日志为本地优先候选后，先定义项目级审计事件 schema，并从已有 artifact 聚合出只读审计时间线，供后续权限矩阵和平台化审计设计复用。

## 已完成

- 新增 `service.commercial_audit_log.get_project_audit_log()`。
- 新增只读 API：`GET /api/stories/<slug>/audit-log`。
- 返回 `version=v1.0-beta-commercial-audit-log-schema-b`、`schema`、`summary`、`events`、`warnings` 与中文 `next_steps`。
- schema 定义未来本地日志文件：`memory/project_audit_log.jsonl`。
- 只读聚合现有项目 artifact：
  - `import_report.json` -> `import_review_generated`
  - `selected_worldline.json` -> `worldline_selected`
  - `memory/master_setting_update_report.json` -> `master_setting_updated`
  - `creation_loop_alpha_closeout.json` -> `creation_loop_closed`
  - 现有 `memory/project_audit_log.jsonl` 行 -> 规范化事件
- 坏 slug 返回 400，缺项目返回 404。
- 损坏的 `project_audit_log.jsonl` 行降级为 warning，不让审计面板 500。

## 边界

- 本刀不让任何写操作追加审计日志，只定义 schema 与只读聚合。
- 不写 `project_audit_log.jsonl`，不覆盖既有 artifact。
- 不接账号、权限系统、对象存储、数据库、队列、计费或不可篡改审计存储。
- 不改变 `run_scene` 默认行为。
- 不改变 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
