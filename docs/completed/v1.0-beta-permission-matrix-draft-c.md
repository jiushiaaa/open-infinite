# v1.0-beta Permission Matrix Draft-C

> 收口日期：2026-06-01
> 性质：owner/editor/viewer 权限矩阵草案，只读报告，不接认证系统、不执行权限拦截。

## 目标

在商业化范围复核和本地审计日志 schema 后，把当前项目工作台、设定编辑、世界线选择、生成动作、审计日志和导出能力映射成后续平台化可用的权限矩阵。

## 已完成

- 新增 `service.commercial_permissions.get_permission_matrix_draft()`。
- 新增只读 API：`GET /api/settings/permission-matrix`。
- 返回 `version=v1.0-beta-permission-matrix-draft-c`、`roles`、`resources`、`enforcement`、`deferred_actions` 与中文 `next_steps`。
- 定义三类角色：
  - `owner`：项目拥有者
  - `editor`：可编辑和执行生成的协作者
  - `viewer`：只读者
- 覆盖六类资源：
  - 项目工作台与项目资产
  - 设定工作台轻编辑
  - 世界线选择与继续起点
  - 生成、续写、干预与状态覆盖
  - 项目审计日志
  - 章节导出与合集导出
- 明确 `enforcement.mode=not_enforced`，避免把草案误当成已接认证或运行时权限。

## 边界

- 不接真实账号、团队空间、认证 provider 或请求上下文。
- 不新增权限拦截，不改变现有 API 行为。
- 不写 artifact，不改变 run/project 产物。
- 不改变 `run_scene` 默认行为。
- 不改变 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
