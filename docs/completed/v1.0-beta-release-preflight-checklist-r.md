# v1.0-beta Release Preflight Checklist-R 收口说明

## 1. 范围

本刀把 v1.0-beta 本地优先商业化加固后的关键证据聚合成发布前只读检查清单，方便在不接真实云端部署的前提下核对“本地闭环是否具备最小发布前证据”。

## 2. 已完成

- 新增 `get_release_preflight_checklist()`。
- 新增 `GET /api/settings/release-preflight`。
- 检查清单聚合本地部署就绪、本地冒烟清单、商业化状态总览、权限矩阵草案，以及项目级版权声明、保留策略和审计导出入口。
- 设置抽屉新增「发布前检查」只读区，展示已具备/需留意数量、前 6 条检查项和中文下一步。
- 未传 `story_slug` 时，项目级版权/保留/审计项降级为“选择具体项目后核对”，不抛错、不白屏。
- `story_slug` 仍走安全校验；非法参数返回 400，缺项目返回 404。

## 3. 边界

- 只读聚合本地证据，不执行真实发布、不主动打 HTTP 请求、不绑定端口、不落盘。
- 不读取或展示明文密钥，不返回 `LLM_API_KEY` / `SEEDREAM_API_KEY` 等环境变量名。
- 不接真实认证、对象存储、云端观测、不可篡改审计或计费系统。
- 不改变 `run_scene`，不影响 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
