# 产品化阶段归类

> 用途：归档解释技术 MVP、产品化 MVP、世界沙盘主线和商业化后置边界。当前下一刀不再从本文派生；请回到 `../../memory.md` 和 `../unfinale-current-optimization-backlog.md`。

## 1. 当前阶段判断

未终章已经越过“只有技术 MVP”的阶段。世界沙盘 S1-S9、卷宗阅读、世界自演结果页、作者采纳、Reviewer 局部重写、编辑后定稿、确认入卷和下一轮入口都有第一版。

现在的核心不是再证明链路存在，而是提高世界沙盘主线质量：

- 真实 LLM 多 Agent 策略博弈。
- 长正文与连续阅读读感。
- 跨章节误会和伏笔回收。
- Reviewer 整章润色。
- 世界状态长期化。

## 2. 阶段边界

| 阶段 | 当前口径 |
| --- | --- |
| 技术 MVP | 已有导入、runner、artifact、API、UI、provider 支撑 |
| 产品化 MVP | 已有世界入口、卷宗阅读、作者链路和下一轮承接 |
| 世界沙盘深化 | 当前主线，详见 `../unfinale-current-optimization-backlog.md` |
| 商业化/发行 | 后置，详见 `../postponed/distribution-phase-plan.md` |

## 3. 不再默认进入

- 商业化、计费、认证、对象存储、多租户。
- 发行安装包、服务器在线体验。
- provider 矩阵和 GraphRAG/Zep 扩张。
- OpenAPI / typed client 面板深化。
