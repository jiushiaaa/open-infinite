# v0.9.1 Provider & Cost Gateway Lite 收口说明

> 收口日期：2026-06-01

## 目标

v0.9.1 的目标是在长篇共创闭环之后，补上真实使用时最先暴露的成本、模型状态和降级可解释性：

```text
运行设置 -> provider 脱敏状态 -> 入口路由解释 -> usage 汇总 -> 手动成本估算 -> 设置页可视化
```

该版本是 Lite 收口，不做完整商业网关，也不把模型路由变成可写策略系统。

## 已完成范围

- `GET /api/settings/providers` 只读返回 provider gateway summary：
  - `routing`：当前文本/视觉路由与 fallback policy。
  - `providers`：主文本模型与 Seedream 视觉模型状态、模型名、base_url、脱敏 key 尾号、usage 来源。
  - `routes`：读者干预生成、主题创世、导入抽取、视觉资产生成四个入口的 provider、mode、runner 与 fallback。
  - `cost_policy`：usage 统计口径、手动单价状态、估算限制。
  - `warnings`：未配置 Key、默认 mock、视觉占位等中文可解释提示。
- `GET /api/settings/provider-usage` 只读聚合已有 usage：
  - 扫描 `intervention_compilation.json` 与 `multi_agent_trace.json` 中的 `generation_meta.usage`。
  - 返回 totals、by_provider、前 50 条 records、缺失 usage 记录数。
  - 支持安全 `story_slug` 过滤，非法 slug 返回 400。
- 设置抽屉新增「模型与用量状态」：
  - 展示 provider 启用状态、模型名、入口路由矩阵、累计 token、输入/输出 token、缺失 usage 与 warning。
  - 保存运行设置或清除密钥后刷新 provider 状态。
- 设置抽屉新增「成本估算」：
  - 手动填写每千输入/输出单价。
  - 仅写当前进程环境变量，不落盘。
  - usage 汇总在配置单价后给出粗略估算。

## 收口证明

本版本由五个小刀组成：

- Provider Gateway Summary-A
- Provider Usage Summary-B
- Provider Status Panel-C
- Manual Price Estimate-D
- Route Matrix-E

- 读者干预生成 -> 本地模拟或主文本模型
- 主题创世 -> 本地模拟或主文本模型

冒烟结果：

- 首页加载为 `未终章 · 阅读工作台`

- 路由矩阵显示四个入口：读者干预生成、主题创世、导入抽取、视觉资产生成

## 边界

- 不持久化 API Key；设置页和接口只展示脱敏尾号。
- 不返回明文 Key，也不在 provider summary 中返回环境变量名。
- 不内置厂商价格表，不联网查价。
- 不新增路由写入开关，不改 `run_scene` 默认行为。
- 不改变 mock / Seedream / runner 的实际调用链。
- 不写项目 artifact，不修改 run 输出契约。
- 不引入 Zep、图数据库、OASIS、CAMEL 或 LangGraph。
- 不做云端队列、对象存储、多租户配置中心或商业计费系统。
