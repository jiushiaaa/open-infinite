# v1.0-beta Settings Local Smoke Checklist-Q 收口说明

## 1. 范围

本刀把本地部署和商业化加固后的关键接口整理成设置页可见的只读冒烟清单，方便每次本地运行后快速核对后端、设置页、项目工作台和审计导出链路。

## 2. 已完成

- 新增 `get_settings_local_smoke_checklist()`。
- 新增 `GET /api/settings/local-smoke-checklist`。
- 清单覆盖首页、故事列表、运行设置、provider、用量、配额观测、本地部署就绪、商业化状态总览、项目工作台和审计日志导出。
- 设置抽屉新增「本地冒烟清单」只读区，展示待核对路径数、外部服务需求、前 6 条路径和运行步骤。

## 3. 边界

- 只生成 checklist，不主动执行 HTTP 请求、不绑定端口、不落盘。
- 不读取或展示明文密钥，不返回 `LLM_API_KEY` / `SEEDREAM_API_KEY` 等环境变量名。
- 不接真实部署、认证、对象存储、云端观测或计费系统。
- 不改变 `run_scene`，不影响 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
