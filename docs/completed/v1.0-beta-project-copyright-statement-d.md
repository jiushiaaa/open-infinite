# v1.0-beta Project Copyright Statement-D

> 收口日期：2026-06-01
> 性质：项目级版权/来源声明 schema，本地轻写，不提供公开发布入口。

## 目标

在导出 share guard 与权限矩阵草案之后，为每个导入项目补一份明确的版权/来源声明，让章节导出与合集导出能引用项目级权利依据，而不是只依赖泛化提示。

## 已完成

- 新增 `service.copyright_statement.get_project_copyright_statement()`。
- 新增 `service.copyright_statement.write_project_copyright_statement()`。
- 新增 API：
  - `GET /api/stories/<slug>/copyright-statement`
  - `POST /api/stories/<slug>/copyright-statement`
- 本地 artifact：`memory/project_copyright_statement.json`。
- 声明 schema 包含：
  - `source_title`
  - `source_author`
  - `rights_holder`
  - `license_status`
  - `permitted_uses`
  - `attestation`
  - `notes`
- 未声明项目会从 `import_report.json` 推断上传来源摘要，并返回 `status=missing` 与中文下一步。
- 损坏声明返回 `status=damaged` 与 `damaged_copyright_statement` warning，不导致 500。
- 内置样例 GET 返回 `status=builtin_sample`；POST 返回 409。
- 单章/合集导出新增 additive `share_guard.rights_basis`，并在 Markdown「版权与分享边界」中写入项目声明状态、来源标题、权利状态和声明用途。

## 边界

- 不开放公开分享、公开发布或商用入口。
- 不接平台级风控、侵权检测、版权审核队列或法律判断。
- 不读取、不回显、不记录任何 API Key。
- 不导出上传原作全文或 holdout 私有正文。
- 不改变 `run_scene` 默认行为。
- 不改变 `chapter.md`、`events.json`、`state_snapshot.json`、`multi_agent_trace.json`、`causal_diff.json` 契约。
