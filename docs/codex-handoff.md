- 作者采纳台首屏已有“当前下一步”工作流中枢，按对照、入账、修订、入卷展示状态，并把写入采纳台、生成草稿、采纳局部改写、确认入卷和回世界沙盘动作前置；顶部“写作台 / 审稿台”可在采纳材料和定稿审阅之间切换，生成采纳记录、草稿、局部改写或确认入卷后会自动聚焦审稿台；下一章 brief 后已有“跨章回收清单”，先把冲突回收、下一轮事件、回读材料、人工复核和正文落点整理成可点击行动，可跳回 brief、长线卷、沙盘、草稿或 Reviewer 质检门；局部修订包摘要后已有“Reviewer 质检门”，先汇总阻断/高优先级审稿项、已选改写、自动定稿和入卷判断，再进入局部改写列表；作者修订稿后已有“整章修订路线”“章节质感雷达”和“定稿对照台”，修订路线把先看风险、再收改写、然后磨正文、最后入卷串成可点击四步，可直达 Reviewer 质检门、采纳已选改写、正文编辑或确认入卷；雷达汇总读感节奏、角色动机、世界入文和入卷准备；对照台把原始草稿、当前定稿、入卷质量门和恢复/采用动作放到确认入卷之前；确认入卷后新增“确认入卷接力台”，先把已成正史、反哺下一轮、Reviewer 定稿和回到世界整理成读确认正文、看阅读链、继续沙盘三个动作；移动端中枢压缩后还提供“调整材料”入口，能直接滚到采纳决策和原大纲/沙盘涌现/作者备注表单。
