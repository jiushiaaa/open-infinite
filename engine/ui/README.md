## 运行

需要先启动引擎后端（提供 `/api/*`）：

```bash
# 在 engine/ 下
lne browse
```

再启动前端开发服务器：

```bash
# 在 engine/ui/ 下
pnpm install
pnpm run dev
```

默认开发地址是 `http://localhost:5173`，`/api` 会代理到 `http://127.0.0.1:8765`。代理目标可用 `LNE_API_TARGET` 覆盖；构建时可用 `VITE_API_BASE` 指定后端绝对地址。

## 校验

```bash
pnpm run typecheck
pnpm run build
```

文档-only 任务通常不需要跑前端 build；改 TS/TSX、路由、类型或样式时必须至少跑 `pnpm run build`。

## 当前路由心智

路由以 `hash` 为主，关键世界沙盘入口包括：

- `#/`：世界书架入口。
- `#/world/<slug>`：世界锚定/世界入口。
- `#/world/<slug>/tianming`：天命书，当前故事卡默认进入的第一站；移动端可用宪法速断条生成/确认、查看锚点、预编译干预或进沙盘。
- `#/world/<slug>/sandbox`：世界沙盘。
- `#/world/<slug>/lens`：多视角活体小说，生成事件多视角并进入卷宗阅读或作者采纳台；移动端可用四格分镜导读条生成、修改事件、进入卷宗阅读或作者台。
- `#/world/<slug>/worldlines/<worldline_id>`：世界线档案；移动端可用四格承接导读条直达最近检查点、具象代偿、自演任务或长线卷。
- `#/world/<slug>/worldlines/<worldline_id>/reading`：卷宗阅读，默认连续阅读。
- `#/world/<slug>/worldlines/<worldline_id>/reading/<tab>`：精准落到某个卷宗 tab，例如 `character_volume` 或 `event_multi_perspective`。
- `#/world/<slug>/worldlines/<worldline_id>/longline`：跨事件长线卷，读取事件、误会、角色记忆、势力压力和作者承接如何持续发酵，并提供阅读进度、多事件索引、误会回收台、未解线索跳转和移动端首屏导读条。
- `#/world/<slug>/worldlines/<worldline_id>/characters/<character_id>`：角色个人卷，读取该角色主观记忆链并展示个人卷正文或明确空态；移动端可用四格导读条直达立场、记忆链、角色目录或作者台。
- `#/world/<slug>/worldlines/<worldline_id>/factions/<faction_id>`：势力卷，读取势力正文、因果压力域和最近代偿记录；移动端可用四格导读条直达站位、代偿、势力目录或作者台。
- `#/world/<slug>/worldlines/<worldline_id>/events/<event_id>/perspectives`：事件多视角详情，读取同一事件的节拍、信息差和证据链；移动端可用四格导读条直达事件、信息差、证据链或作者台。
- `#/world/<slug>/worldlines/<worldline_id>/checkpoints/<run_id>/<checkpoint_id>`：检查点回放；移动端可用四格醒来导读条直达连续阅读、角色记忆、具象代偿或作者台。
- `#/world/<slug>/author-adoption/<adoption_run_id>`：作者采纳台。

## 结构

```text
src/
  api/            client.ts / types.ts，封装 HTTP API 与前端契约类型
  components/     页面、卷宗、沙盘、作者台、设置和机制档案组件
  styles/         theme.css / global.css，古风纸面设计令牌
  routing.ts      hash 路由解析与构建
  markdown.tsx    小说正文 Markdown 渲染
  motion.ts       强反馈动效降级开关
  storyShelfFocus.ts 世界书架故事卡阶段、推荐世界、四段旅程脉冲与推荐下一步推导
  dossierReadingFocus.ts 卷宗阅读当前场景导读状态推导
  readingProgress.ts 本机最近阅读续航，记录阅读类路由并供锚定页和 AppShell 续读
  worldRouteContext.ts 世界内路由语境，供 WorldWorkspaceShell 显示当前位置、旅程总线、工作区总览、当前任务条、世界脉搏、体验轨道、卷宗速览和下一步动作
  worldJourney.ts 世界锚定页旅程状态与世界脉搏推导，供卷宗总览推荐下一步
```
